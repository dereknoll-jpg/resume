# Derek Noll Resume Workspace

This is a small React workspace for editing Derek Noll's resume and exporting it to a clean PDF.

## Run

```powershell
npm install
npm run dev
```

Open the local URL Vite prints, edit the resume in the left panel, and use **Export PDF** to open the browser print dialog. Choose **Save as PDF**.

## Keep Updating

Changes are saved automatically in the browser's local storage. Use **Download Data** to keep a portable JSON copy of the resume content, and **Import Data** to restore or move it to another browser.
